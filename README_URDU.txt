=====================================================
   انٹر کام ایپ — سیٹ اپ کی ہدایات (اردو)
=====================================================

اس زِپ میں یہ فائلیں ہیں:
  • index.html          — پوری ایپ
  • config.js           — پاس ورڈ، نام اور فائر بیس کی ترتیبات (صرف یہی فائل بدلنی ہے)
  • database.rules.json — ڈیٹا بیس کے اصول (اختیاری، نیچے دیکھیں)

-----------------------------------------------------
مرحلہ 1:  پاس ورڈ بدلنا
-----------------------------------------------------
1) config.js کو نوٹ پیڈ (Notepad) میں کھولیں۔
2) اوپر یہ دو لائنیں ہیں:
      const ADMIN_ID       = "admin";
      const ADMIN_PASSWORD = "1234";
   انہیں اپنی مرضی کے آئی ڈی/پاس ورڈ سے بدل دیں اور فائل محفوظ (Save) کریں۔

-----------------------------------------------------
مرحلہ 2:  مفت فائر بیس بنانا
-----------------------------------------------------
1) براؤزر میں   https://console.firebase.google.com   کھولیں اور اپنے گوگل اکاؤنٹ سے لاگ اِن کریں۔
2) "Create a project" (یا Add project) دبائیں → کوئی نام لکھیں (مثلاً intercom) → Continue۔
   "Google Analytics" بند (Disable) کر دیں → Create project۔
3) پروجیکٹ کھلنے کے بعد بائیں مینو میں:  Build → Realtime Database  پر جائیں۔
4) "Create Database" دبائیں۔ لوکیشن جو بھی ہو (جیسے United States) چن لیں۔
5) "Start in test mode" چنیں → Enable۔
6) اوپر "Rules" ٹیب میں جا کر database.rules.json کا مواد کاپی کر کے پیسٹ کریں → Publish۔
   (اس سے صرف messages والا حصہ کھلا رہتا ہے اور پیغام 500 حروف تک محدود ہوتا ہے۔)
7) اب "Data" ٹیب میں اوپر ایک لنک نظر آئے گا جیسے:
        https://xxxx-default-rtdb.firebaseio.com
   یہی آپ کا databaseURL ہے۔

-----------------------------------------------------
مرحلہ 3:  فائر بیس کی ترتیبات config.js میں ڈالنا
-----------------------------------------------------
1) فائر بیس میں بائیں اوپر ️ (Settings) → Project settings۔
2) نیچے "Your apps" میں   </>   (Web) کا آئیکن دبائیں۔
3) کوئی نام لکھیں (مثلاً intercom-web) → Register app۔
   ("Firebase Hosting" کا ٹک نہ لگائیں)۔
4) آپ کو firebaseConfig کا کوڈ نظر آئے گا:
        const firebaseConfig = {
          apiKey: "....",
          authDomain: "....",
          databaseURL: "....",
          projectId: "....",
          ...
        };
5) اس میں سے { } کے اندر کی ساری قدریں کاپی کریں اور config.js میں
   FIREBASE_CONFIG کے اندر اسی طرح پیسٹ کر دیں۔
   دھیان رکھیں کہ databaseURL موجود ہو۔
   (اگر databaseURL نظر نہ آئے تو مرحلہ 2 والا لنک خود لکھ دیں۔)
6) فائل محفوظ کریں۔

-----------------------------------------------------
مرحلہ 4:  ایپ کو انٹرنیٹ پر چڑھانا (تاکہ سب موبائل/کمپیوٹر پر چلے)
-----------------------------------------------------
️ اہم: مائیک سے اردو لکھنے کے لیے لازمی ہے کہ ایپ https:// والے لنک پر کھلے۔
   فائل کو ڈبل کلک کر کے کھولنے سے مائیک ٹھیک کام نہیں کرتا۔

سب سے آسان طریقہ — Netlify Drop (مفت):
1) https://app.netlify.com/drop کھولیں۔
2) اس زِپ کو کھول کر (Extract) پورا فولڈر وہاں ڈریگ اینڈ ڈراپ کر دیں۔
3) چند سیکنڈ میں آپ کو ایک لنک ملے گا، مثلاً  https://xyz.netlify.app
4) یہی لنک اوپر والی منزل اور نیچے والی منزل کے سب فونز/کمپیوٹرز میں کھولیں۔

دوسرا طریقہ — Vercel یا Firebase Hosting بھی استعمال ہو سکتے ہیں۔

-----------------------------------------------------
مرحلہ 5:  دونوں منزلوں پر استعمال
-----------------------------------------------------
اوپر کی منزل (پیغام وصول کرنے والے):
  • لنک کھولیں → آئی ڈی/پاس ورڈ ڈال کر داخل ہوں۔
  • اگر اوپر زرد پٹی "آواز فعال کرنے کے لیے یہاں دبائیں" نظر آئے تو ایک بار دبا دیں۔
  • فون/کمپیوٹر کی آواز (Volume) کھلی رکھیں اور براؤزر کھلا رکھیں۔
  • پیغام آتے ہی ہلکی گھنٹی بجے گی اور نام کے نیچے بڑے حروف میں پیغام آئے گا۔
  • دوا دے دینے کے بعد "پڑھ لیا / صاف کریں" دبائیں۔

نیچے کی منزل (پیغام بھیجنے والے):
  • اسی لنک پر لاگ اِن کریں۔
  • جس شخص کو پیغام دینا ہو اس کے بڑے بٹن (مثلاً سہیل) کو دبائیں۔
  • پیغام ٹائپ کریں، یا  دبا کر اردو میں بولیں۔
    (پہلی بار براؤزر مائیک کی اجازت مانگے گا → "Allow / اجازت دیں" دبائیں۔)
  • "بھیجیں" دبائیں۔ پیغام فوراً اوپر پہنچ جائے گا۔

-----------------------------------------------------
مفید مشورے
-----------------------------------------------------
• مائیک کے لیے اینڈرائیڈ پر گوگل کروم (Chrome) استعمال کریں۔ آئی فون پر سفاری میں اردو آواز بعض اوقات کم چلتی ہے — ایسی صورت میں کی بورڈ کا مائیک استعمال کریں۔
• فون کی ہوم اسکرین پر شارٹ کٹ بنانے کے لیے: کروم مینو (⋮) → "Add to Home screen"۔
• اوپر والی منزل کے فون/کمپیوٹر کی اسکرین بند نہ ہونے دیں، ورنہ گھنٹی نہیں بجے گی۔ ممکن ہو تو اس کے لیے "Screen timeout" بڑھا دیں یا چارجنگ پر لگا رہنے دیں۔
• نام بدلنے ہوں تو config.js میں PEOPLE کی فہرست میں نام بدل دیں۔
• یاد رہے: لاگ اِن کا پاس ورڈ سادہ سطح کا ہے (کوڈ کے اندر ہے)، یہ دفتر/دکان کے اندرونی استعمال کے لیے کافی ہے۔
  پیغامات میں حساس معلومات (جیسے شناختی کارڈ نمبر) نہ لکھیں۔

اللہ کرے آپ کا کام آسان ہو! 

-----------------------------------------------------
اسکرین ہمیشہ آن رکھنا (نیا فیچر)
-----------------------------------------------------
• لاگ اِن کے بعد اسکرین خود بخود آن رہتی ہے۔
• نیچے بائیں کونے میں "اسکرین ہمیشہ آن ہے — بند کریں" کا بٹن ہے۔ اسے دبائیں تو یہ سیٹنگ بند ہو جائے گی، دوبارہ دبائیں تو چل پڑے گی۔
• ایپ کھلی اور سامنے (فرنٹ) میں ہونی چاہیے۔ دوسری ایپ پر جانے سے لاک خود ہٹ جاتا ہے اور واپس آنے پر دوبارہ لگ جاتا ہے۔

-----------------------------------------------------
سابقہ پیغامات کا ریکارڈ / ہسٹری (نیا فیچر)
-----------------------------------------------------
• جب کوئی پیغام "پڑھ لیا / صاف کریں" سے ہٹایا جاتا ہے تو وہ ضائع نہیں ہوتا بلکہ ہسٹری میں محفوظ ہو جاتا ہے۔
• نیچے بائیں جانب " سابقہ پیغامات" کا نیا بٹن شامل کیا گیا ہے۔
• اسے دبانے پر آخری 50 پیغامات کا تفصیلی ریکارڈ کھلتا ہے، جس میں:
    - کس کے نام پیغام تھا (رنگین کارڈ اور آئیکن سمیت)
    - اصل پیغام کی عبارت
    - پیغام بھیجے جانے کا وقت اور پڑھے جانے / صاف ہونے کا وقت
• اوپر نام کے بٹنوں (جیسے سہیل، ابرار وغیرہ) پر کلک کر کے کسی مخصوص شخص کے پرانے پیغامات بھی فلٹر کیے جا سکتے ہیں۔
• اگر Firebase Rules کا استعمال کر رہے ہیں تو database.rules.json میں history کے قواعد بھی شامل کر دیے گئے ہیں تاکہ سب ڈیوائسز پر ہسٹری اپ ڈیٹ رہے۔

2) اوپر والی منزل کے افراد (ہر فرد کا الگ لاگ اِن):

   • دوسرے افراد کے پیغامات اس کی اسکرین پر بالکل نہیں آئیں گے اور نہ ہی ان کی گھنٹی بجے گی۔
   • گھنٹی صرف اسی وقت بجے گی جب پیغام مخصوص اسی فرد کے لیے بھیجا گیا ہو۔

-----------------------------------------------------
مائیک (Voice Typing) کے کام نہ کرنے کی اصل وجہ اور حل
-----------------------------------------------------
• گوگل کروم براؤزر سیکیورٹی کے اصولوں کی وجہ سے جب کوئی فائل ڈبل کلک کر کے (file:///) کھولی جائے تو مائیک مکمل بلاک کر دیتا ہے۔
• حل: اس فولڈر میں موجود "start-server.bat" فائل پر ڈبل کلک کریں۔
  اس سے آپ کے کمپیوٹر پر ایک لوکل لنک چلے گا (http://localhost:3000)۔
  اس لنک پر مائیک 100 فیصد بالکل درست بول کر اردو ٹائپ کرے گا!
• موبائل یا دوسری منزل کے لیے: ایپ کو Netlify Drop پر اپلوڈ کریں (جو https:// لنک دیتا ہے)، وہاں بھی مائیک بہترین چلے گا۔
• بولنے کے لیے مائیک دبا کر تسلی سے بولیں: "بھائی ٹوکن نمبر چار کو یہ دے دیں"۔
• ایپ میں فوری ٹوکن بٹنز (Quick Chips) بھی شامل کر دیے گئے ہیں تاکہ ایک کلک پر بھی ٹوکن اور عام جملے لکھے جا سکیں۔

-----------------------------------------------------
ایڈمن اور وصول کنندہ کے اسکرین کا فرق
-----------------------------------------------------
• ایڈمن پینل (نیچے کی منزل):
  - جب ایڈمن پیغام بھیجتا ہے تو ایڈمن کے کارڈ پر "پڑھ لیا / صاف کریں" کا بٹن نہیں آئے گا، بلکہ:
    "⏳ زیرِ التواء — پڑھنے کا انتظار" اور " پیغام واپس لیں" کا بٹن آئے گا۔
  - ایڈمن کو پتا رہے گا کہ پیغام چلا گیا ہے اور ابھی سہیل نے پڑھا نہیں۔
  - جب سہیل دوسری منزل پر پیغام پڑھ کر "صاف کریں" دبائے گا، تو ایڈمن کے اسکرین سے بھی پیغام خود بخود غائب ہو جائے گا اور ایڈمن کو اطلاع مل جائے گی کہ "سہیل نے پیغام پڑھ لیا ہے"۔

• سہیل / ملازم کی اسکرین (دوسری منزل):
  - سہیل کی اسکرین پر اصل پیغام بڑے جلی حروف میں آئے گا اور ساتھ میں بڑا سبز بٹن " پڑھ لیا / صاف کریں" آئے گا۔
  - سہیل جب کام مکمل کر لے گا تو وہ بٹن دبائے گا، جس سے پیغام ہسٹری میں چلا جائے گا۔

-----------------------------------------------------
دو طرفہ گفتگو اور "جواب دیں" (نیا فیچر)
-----------------------------------------------------
اب ایڈمن اور ملازم کے درمیان باقاعدہ گفتگو / چیٹ ممکن ہے:

1) ایڈمن نے پیغام بھیجا:
   • مثلاً: "ایک ہفتے کی دوا دے دو"
   • سہیل کے اسکرین پر پیغام آئے گا اور ساتھ میں دو بٹن ہوں گے:
     -  جواب دیں (Reply)
     -  کام ہو گیا / صاف کریں (Done / Clear)

2) مریض کا سوال اور سہیل کا جواب:
   • مریض کہتا ہے "میں دور سے آیا ہوں"۔
   • سہیل " جواب دیں" دبائے گا تو جواب کا باکس کھلے گا جس میں پچھلے پیغام کا حوالہ لکھا ہوگا۔
   • سہیل مائیک سے بولے گا یا بٹن دبائے گا: "کیا میں اس کو دو ہفتے کی دے دوں؟" اور "بھیجیں" دبا دے گا۔

3) ایڈمن کے اسکرین پر اطلاع اور جوابی پیغام:
   • ایڈمن کے فون پر گھنٹی بجے گی اور سہیل کے کارڈ کے نیچے سہیل کا سوال شو ہو جائے گا۔
   • ایڈمن بھی " جواب دیں" دبا کر فوراً "جی، دے دیں" بھیج دے گا۔

4) کام مکمل ہونا:
   • سہیل مریض کو دوا دے کر " کام ہو گیا / صاف کریں" دبائے گا تو پورا سیشن ہسٹری میں محفوظ ہو کر اسکرین سے صاف ہو جائے گا۔

-----------------------------------------------------
سپر یوزر / مینیجر پینل اور 1-کلک پن پیغامات (نیا اپ ڈیٹ)
-----------------------------------------------------
1) رش کے وقت ایک کلک پر پیغام بھیجنا (Pinned Buttons):
   • ایڈمن پینل پر ہر فرد کے کارڈ کے اوپر " فوری پن پیغامات" کی پٹی شامل کر دی گئی ہے۔
   • مثلاً سہیل کے کارڈ پر براہِ راست بٹن نظر آئیں گے:
     [ پیناڈول دے دو] [ ایک ہفتے کی دوا] [ دو ہفتے کی دوا]
   • رش کے وقت کچھ بھی ٹائپ کرنے یا بولنے کی ضرورت نہیں، صرف [ پیناڈول دے دو] پر کلک کریں، پیغام اسی لمحے سہیل کو چلا جائے گا!

2) ایڈمن کا ایک کلک پر جوابی پیغام (Quick Reply):
   • جب سہیل کوئی سوال پوچھے گا (مثلاً: "کیا میں دو ہفتے کی دے دوں؟") تو ایڈمن کے کارڈ پر نیچے خودکار فوری بٹن آ جائیں گے:
     [ جی، دے دیں] [ نہیں، نہ دیں] [ ایک منٹ رکیں] [ ڈاکٹر سے پوچھیں]
   • ایڈمن صرف [ جی، دے دیں] کو دبائے گا اور جوابی پیغام فوراً سہیل کو موصول ہو جائے گا!
   • اگر تفصیلی بات کرنی ہو تو ساتھ " جوابی پیغام لکھیں" کا بٹن بھی موجود ہے۔

3) سپر یوزر / مینیجر پینل (افراد اور پن بٹنز کا انتظام):
   • ایڈمن اسکرین کے اوپر "️ مینیجر پینل" کا جامنی بٹن موجود ہے۔
   • ٹیب 1 (افراد کا انتظام):
     - نئے ملازمین / افراد کو نام، آئی ڈی اور پاس ورڈ دے کر شامل کر سکتے ہیں، یا پرانے افراد کو ہٹا سکتے ہیں۔
   • ٹیب 2 (پن پیغامات کا انتظام):
     - ہر فرد (مثلاً سہیل) کے لیے نئے پن بٹن (مثلاً "پیناڈول دے دو") شامل کر سکتے ہیں یا پرانے ڈیلیٹ کر سکتے ہیں۔
     - یہ سیٹنگز تمام ڈیوائسز پر فوری اپ ڈیٹ ہو جاتی ہیں۔
