# User Preferences & Communication Rules

- **Response Language**: Hamesha **Roman Urdu** (Urdu written in Latin/English letters, maslan "Maine yeh kaam mukammal kar diya hai") mein hi jawab dena hai, chahe user kisi bhi zaban (English, Urdu script, Roman Urdu, waghera) mein sawal poochhe.
- Project ke code ya app ke andar ka text Urdu script (RTL) mein rahega, lekin user ke sath chat/conversation mein jawab hamesha Roman Urdu mein dena hai.
